

## Run in VS Code
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` → **Open with Live Server**.

## Personalize
Open `script.js`. At the top edit:
- `herName`
- `myName`
- `personalLetter`
- `secretMessage`
- `balloons`
- `reasons`
- photo arrays
- `finalPhoto`

## Add photos
Put your photos in `assets/photos/`:
- her-1.jpg through her-6.jpg
- our-1.jpg through our-4.jpg
- best-photo.jpg

If a photo is missing, a placeholder is shown.

## Add song
Put your MP3 at:
`assets/audio/birthday-song.mp3`

The site intentionally waits for a user click before playing audio because modern browsers block unsolicited autoplay.

## Free publishing
Use GitHub Pages:
1. Create a public GitHub repository.
2. Upload the entire project.
3. Repository → Settings → Pages.
4. Source: Deploy from branch.
5. Branch: `main`, folder `/root`.
6. Save.

GitHub will provide the public URL.

## No backend required
This project is plain HTML/CSS/JavaScript. No database, API key or paid hosting is required.
